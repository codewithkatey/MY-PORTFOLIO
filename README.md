# Sheryn Kate Calingasan — Portfolio

Personal portfolio site for **Sheryn Kate Calingasan**, Junior Software Developer.

Built with React, Material UI, and Framer Motion.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
```

## Deploy

Compatible with Vercel, Netlify, or any static host. Serve the `build/` folder.

## Customize content

- `src/static/profile.js` — bio, experience, skills, contact
- `src/static/projects.js` — project cards
